Part 2 — encrypted recovery map (only if enabled)

      
The full recovery guide. It is encrypted in your browser — the password and the plaintext never reach the server. The server stores only the ciphertext blob. The heir unlocks it with the password they already hold, on the standalone decrypt page.

      
Interim crypto: this build derives the key with PBKDF2 (250,000 iterations, SHA-256). The spec calls for Argon2id — the KDF will be swapped for argon2-browser (WASM) before real use. Do not rely on Part 2 for real funds yet.
